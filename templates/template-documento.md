## Estilo de títulos

```
# Título principal (portada)
## Título de sección (ej: 1. Introducción)
### Título de subsección (ej: 1.1. Antecedentes)
#### Título de sub-subsección (ej: 1.1.1. Detalle)
```

## Estilo de tablas

Las tablas deben tener encabezados claros y estar numeradas si hay más de una. Usar el formato Markdown estándar:

| Columna 1 | Columna 2 | Columna 3 |
|-----------|-----------|-----------|
| Celda | Celda | Celda |

Las tablas deben estar precedidas por su referencia: `Tabla 1: Descripción de la tabla`.

## Estilo de figuras y diagramas

Toda imagen debe incluir:
- Texto alternativo (alt text)
- Leyenda numerada debajo: `Figura 1: Descripción de la figura`
- Resolución suficiente para ser legible

Formatos aceptados: PNG, SVG (preferido para diagramas).

## Estilo de código y configuraciones

Los fragmentos de código deben usar bloques con sintaxis destacada:

```bash
comando --ejemplo
```

```yaml
clave: valor
```

```python
print("ejemplo")
```

Para configuraciones de red, indicar el lenguaje del bloque (bash, routeros, yaml, json, etc.).

## Referencias bibliográficas

Usar formato APA, IEEE o ACM consistente a lo largo de todo el documento.

**Ejemplos APA:**
- Libro: Apellido, A. (año). *Título*. Editorial.
- Paper: Apellido, A. (año). Título del artículo. *Nombre de la revista*, *volumen*(número), páginas.
- RFC: IETF. (año). *RFC NNNN: Título*. Recuperado de https://datatracker.ietf.org/doc/rfcNNNN/
- Documentación técnica: Empresa. (año). *Título del documento*. Recuperado de [URL]
