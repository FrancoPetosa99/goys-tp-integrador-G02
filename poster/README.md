# Póster A1 — Feria de Redes GOYS 2026

## Formato
- Tamaño: **A1** (594 × 841 mm)
- Orientación: **Vertical** (recomendada) u horizontal
- Contenido: **autocontenido** (debe entenderse sin necesidad de que el autor explique)

## Estructura recomendada (vertical)

```
┌──────────────────────────────────────┐
│         TÍTULO DEL PROYECTO           │
│       Grupo XX - Integrantes          │
├──────────────────────────────────────┤
│  Introducción / Objetivos            │
├──────────────┬───────────────────────┤
│  Diagrama    │  Metodología          │
│  de red      │  (qué hicieron)       │
├──────────────┴───────────────────────┤
│  Resultados principales              │
│  (capturas, tablas, gráficos)        │
├──────────────────────────────────────┤
│  Conclusiones                        │
│  (logros, limitaciones, trabajo fut) │
├──────────────────────────────────────┤
│  Referencias + Código QR al repo     │
└──────────────────────────────────────┘
```

## Qué debe incluir SÍ o SÍ
- Título del proyecto
- Nombre del grupo e integrantes
- Contexto/objetivo (¿qué problema resuelve?)
- Diagrama de la solución (topología de red)
- Resultados (capturas, métricas, tablas)
- Conclusiones
- Código QR al repositorio

## Qué NO debe tener
- Párrafos largos (nadie los lee en un póster)
- Letra menor a 24pt (no se lee desde 1m)
- Más de 3 colores distintos
- Más de 2 tipografías distintas

## Consejos de diseño
- Usá el [template PNG incluido] como guía de dimensiones
- Título visible desde 3 metros (mínimo 48pt)
- Secciones con headers claros
- Diagramas > texto
- Usá el QR al repo para que la gente pueda acceder a los detalles
- Impresión: recomendado en papel fotográfico o bond 120g+
